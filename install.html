Instalar complemento

Si en Android no aparece el aviso de instalación:

  1. Toca el botón de arriba para descargar el archivo .xpi.
  2. Abre el gestor de archivos y toca el archivo descargado.
  3. Elige abrir con Firefox. Debería aparecer el aviso "Agregar complemento".
